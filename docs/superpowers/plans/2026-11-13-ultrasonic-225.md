# Ultrasonic 2.2.5 implementation plan

**Goal:** Add two explicitly selected high-frequency voice profiles and publish tested Windows 2.2.5 builds.

**Architecture:** Keep the common FFmpeg preview/export pipeline and existing schema 2. Add ULTRASONIC (25 kHz, 96 kHz output) and NEAR (20 kHz, 48 kHz output). Use band-limited 300–3000 Hz speech with double-sideband suppressed-carrier modulation: occupied bands approximately 22–28 kHz and 17–23 kHz. Modulate at 96 kHz before final antialias resampling. No claims of equivalent perception or effectiveness.

**Constraints:** WAV/FLAC PCM24 only for new profiles. Never normalize ultrasonic energy to a LUFS target. Bound vocal peaks to −24 dBFS; attenuation-only full-mix peak ceiling −6 dBTP. Preserve user gains below ceiling, timing, mute/solo, reverse and speed. Report full-band stereo/peak measurements; LUFS is informational, may be undefined. Warn that OS/browser resampling and transducer bandwidth can remove the signal; silence is not a reason to raise volume. Existing profiles retain their mastering behavior.
