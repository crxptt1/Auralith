# Auralith Studio 2.2.5

## Polski

- **Ultrasonic 25 kHz** — modulacja nagranych afirmacji; eksport WAV/FLAC 24-bit / 96 kHz, pasmo głosu około 22–28 kHz.
- **Near-ultrasonic 20 kHz** — alternatywa dla wyjść 48 kHz; WAV/FLAC 24-bit / 48 kHz, pasmo około 17–23 kHz. Niektóre osoby mogą je słyszeć.
- Oba profile są dostępne w Studio i Eksportach. Zachowują ustawienia warstw i zapisują się w projekcie. Dotychczasowe tryby pozostają bez zmian.
- Kontrola pełnego pasma, ograniczenie szczytów głosu do −24 dBFS i miksu do −6 dBTP, bez podbijania do celu LUFS. MP3 jest niedostępny dla obu profili. Eksportuj je osobno; komplet nadal zawiera CLEAR / LOW / MASKED / DEEP.

Samo wsparcie 48/96 kHz nie gwarantuje pasma słuchawek ani głośnika. Dla 25 kHz potrzebny jest cały tor 96 kHz; system, Bluetooth lub odtwarzacz mogą filtrować albo resamplować sygnał. **Nie zwiększaj głośności, gdy nic nie słychać.** To obróbka sygnału, nie dowód skuteczności afirmacji.

Pobierz **Setup.exe** do instalacji lub **Portable.exe** do samodzielnego uruchomienia. Pliki `.blockmap` i `latest.yml` są metadanymi aktualizacji. Program nie jest podpisany cyfrowo.

## English

- **Ultrasonic 25 kHz** — modulation of your recorded affirmations; WAV/FLAC 24-bit / 96 kHz exports, voice band approximately 22–28 kHz.
- **Near-ultrasonic 20 kHz** — an alternative for 48 kHz outputs; WAV/FLAC 24-bit / 48 kHz, approximately 17–23 kHz. Some people can hear it.
- Both profiles are available in Studio and Exports, retain layer settings and persist in projects. Existing profiles remain unchanged.
- Full-band QC, voice peaks capped at −24 dBFS and mix peaks at −6 dBTP, without boosting to a LUFS target. MP3 is unavailable for these profiles. Export them individually; the batch still contains CLEAR / LOW / MASKED / DEEP.

48/96 kHz support alone does not guarantee headphone or speaker bandwidth. 25 kHz needs an end-to-end 96 kHz output path; the OS, Bluetooth or player may filter or resample the signal. **Do not raise volume to hear it.** Signal processing does not establish affirmation effectiveness.

Download **Setup.exe** for installation or **Portable.exe** to run standalone. `.blockmap` and `latest.yml` are update metadata. The application is unsigned.
